1. CREATE THE PROJECT
---------------------
mkdir rask-api

cd rask.api

2. INITIALIZE A NODE PROJECT
----------------------------
npm init -y

This creates>>>
task-api/
↳ package.json

What just happened?

npm init -y did not create an application.

It created the project's package manifest.

package.json tells Node/npm things such as:

project name
version
scripts
dependencies


3. INSTALL TYPESCRIPT
---------------------
npm install -D typescript

After this the project will carr>>>
task-api/
node_modules
package-lock.json
package.json


package.json will carry>>>
"devDependencies": {
  "typescript": "..."
}


4. CREATE THE TYPESCRIPT CONFIGURATION
--------------------------------------
npx tsc --init

This creates>>>
tsconfig.json

What is tsconfig.json?

It tells the TypeScript compiler:

“Here is how I want you to treat and compile my TypeScript project.”

This file will become important later.

Don't try to understand every option today.


5. CREATE THE FIRST TYPESCRIPT file
-----------------------------------
touch src/index.ts

Add this in index.ts
↳
const message: string = "Hello from TypeScript";

console.log(message);

Now we have >>>
task-api/
├── src/
│   └── index.ts
│   └── index.d.ts
│   └── index.d.ts.map
│   └── index.js.map
├── package.json
├── package-lock.json
└── tsconfig.json

6. COMPILE It
-------------
npx tsc

This tells the TypeScript compiler: --1. 1
Read the project according to tsconfig.json and compile the TypeScript.
Depending on the configuration generated by your TypeScript version, the JavaScript output may appear in a different location.
